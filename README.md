# Apple Financial Report Research

![Apple financial analysis project cover](assets/recruiter/cover.png)

> **Portfolio lens:** An evidence-led financial-analysis assignment that makes its source material, calculations, charts, and final deliverables easy to inspect.

This repository contains the research, calculations, visual material, and final deliverables for an Apple Inc. financial-analysis assignment. The work compares Apple's 2023 and 2024 filings through profitability, liquidity, efficiency, working-capital, and gearing ratios.

## Start here

- `Executive_Summary.md` gives the main findings.
- `Apple_Financial_Analysis_Report_Updated.md` is the editable Markdown report.
- `Apple_Financial_Analysis_Report.docx` is the Word deliverable.
- `report/financial_accounting_report.pdf` is the finished LaTeX/PDF version.
- `Assignment.pdf` and `FINANCIAL_STATEMENTS_GUIDE.md` provide the assignment context.

## Source material and outputs

The 2023 and 2024 Apple 10-K filings are retained in both HTML and PDF form. `apple_financial_ratios.csv` holds the calculated ratios. The PNG charts at the repository root are the figures used in the Markdown/Word workflow; the matching copies in `report/figures/` are retained for the LaTeX report.

## Recreating charts

The visualizations are generated by `create_visualizations.py` and `create_additional_visualizations.py`. Run them in a Python environment with their imports installed only when you intend to refresh the committed figure files:

```bash
python create_visualizations.py
python create_additional_visualizations.py
```

The LaTeX source and bibliography live in `report/`. Compiling that version requires a full LaTeX installation with bibliography support; the completed PDF is already included for reading.
