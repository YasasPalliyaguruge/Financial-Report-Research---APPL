# Apple Inc. Financial Analysis (AAPL)

![Apple financial analysis project cover](assets/recruiter/cover.png)

A reproducible financial-accounting case study built from Apple Inc.'s 2023 and 2024 annual filings. The repository brings the source reports, ratio calculations, visualisations and final written deliverables together so the analysis can be inspected from evidence to conclusion.

> The repository URL contains the legacy ticker typo `APPL`; Apple's correct ticker is `AAPL`. Renaming the repository is tracked separately because it changes the public URL.

## Analysis scope

The project compares Apple's 2024 financial performance with 2023 across four areas:

- **Profitability** — gross, operating and net margins; return on assets; return on equity
- **Liquidity** — current, quick and cash ratios
- **Operating efficiency** — asset turnover, inventory turnover, days inventory outstanding, receivables turnover and days sales outstanding
- **Capital structure** — debt-to-equity, debt-to-assets and equity ratios

The source filings are retained in the repository in HTML and PDF formats. Calculated values are stored in [`apple_financial_ratios.csv`](apple_financial_ratios.csv), while the written reports explain the accounting interpretation and business implications.

## Key findings from the included calculations

| Metric | 2024 | 2023 | Movement |
|---|---:|---:|---:|
| Gross profit margin | 46.21% | 44.13% | +2.08 percentage points |
| Operating profit margin | 31.51% | 29.82% | +1.69 percentage points |
| Net profit margin | 23.97% | 25.31% | -1.33 percentage points |
| Return on assets | 25.68% | 27.51% | -1.83 percentage points |
| Return on equity | 164.59% | 156.08% | +8.52 percentage points |
| Current ratio | 0.87 | 0.99 | -0.12 |
| Inventory turnover | 53.67× | 60.54× | -6.87× |
| Days sales outstanding | 31.19 days | 28.10 days | +3.09 days |
| Debt-to-equity | 1.70 | 1.69 | broadly stable |
| Debt-to-assets | 0.26 | 0.30 | improved by 0.03 |

The analysis therefore identifies stronger gross and operating profitability alongside weaker short-term liquidity and some slowing in inventory and receivables efficiency. Apple's reported operating cash flow of approximately $118.3 billion is discussed as an important counterbalance when interpreting the liquidity ratios.

## Reproducing the visualisations

The charts are generated by:

```bash
python create_visualizations.py
python create_additional_visualizations.py
```

Create a Python environment and install the libraries imported by those scripts before regenerating the committed figures. The LaTeX version requires a complete LaTeX toolchain with bibliography support.

## Methodology and interpretation boundaries

- Filing-derived figures and calculated ratios can be traced to the retained source reports and CSV output.
- Ratio movements are descriptive; they do not by themselves establish causation.
- Apple's unusually high return on equity is affected by its equity base and share-repurchase programme, so it should not be interpreted as a standalone operating-performance measure.
- External industry benchmarks are separate from Apple's audited filings and should be checked against their original sources before professional reuse.
- Statements about strategy, competitive position and recommended actions are analytical interpretations prepared for the assignment, not investment advice.
